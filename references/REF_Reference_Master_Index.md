# Studio Game Design Reviewer — Integrated Reference Master Index

> 프로젝트 소스 파일 수 제한에 대응하기 위해 68개 Case Study를 5개 Layer 문서로 통합한 패키지다.

## 업로드 권장 파일
1. `Layer_1_Core_Design.md`
2. `Layer_2_Specialized.md`
3. `Layer_3_Solo_Micro_Production.md`
4. `Layer_4_Commercial.md`
5. `Layer_5_Korean_Selection.md`
6. `Reference_Master_Index.md`

별도로 Reviewer Project Instructions와 Final Evaluation Template를 함께 유지한다.

## Layer 역할
- **Layer 1 — Core Design:** 좋은 게임 설계인가?
- **Layer 2 — Specialized:** 특수 설계 문제를 어떻게 해결하는가?
- **Layer 3 — Solo/Micro Production:** 작은 팀이 실제로 만들 수 있는가?
- **Layer 4 — Commercial:** 10K~50K, 상방 100K 목표의 투입이 합리적인가?
- **Layer 5 — Korean Selection:** 국내 경연·전시·지원 심사에서 경쟁력이 있는가?
